# Código de Conducta para Malicious Repo CTI

Este proyecto se rige por un código de conducta estricto para mantener un entorno profesional y seguro, dado que tratamos con inteligencia de amenazas.

## Reglas básicas

1. **Comportamiento profesional:** No se tolerarán insultos, acosos, comentarios despectivos o cualquier comportamiento que pueda considerarse poco ético.
2. **Confidencialidad:** Si se comparte información sensible (ej. IOCs de campañas activas), no se debe utilizar para atacar sistemas, sino solo para defenderse.
3. **Veracidad:** Toda la información compartida debe estar respaldada por evidencia. No se permiten falsas alarmas o desinformación.
4. **Respeto a la propiedad intelectual:** No se deben compartir muestras de malware que infrinjan derechos de autor o leyes locales. Usa solo hashes y descripciones.

## Reporte de incidentes

Si alguien viola este código de conducta, repórtalo a condor2026@proton.me. El equipo del proyecto tomará las medidas adecuadas, que pueden incluir la expulsión del colaborador.

## Agradecimiento

Este código de conducta está inspirado en el Contributor Covenant y adaptado a las necesidades de la comunidad de ciberseguridad.
